What is a 404 page?

When you ask a website for a page that is not there, the server answers with the code 404, which means "not found". A 404 page is the friendly page you see instead of a blank error. A good one explains what happened and gives people a way forward, so they do not leave. Businesses care because every lost visitor is a lost customer.
