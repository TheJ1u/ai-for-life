# AGENTS.md

This repo is the AI For Life club website, a plain static HTML site. All instructions for AI assistants are in [CLAUDE.md](CLAUDE.md). Read that file first and follow it, whichever assistant you are.

Short version:
- The contributor is probably a beginner. Explain simply, make small changes, and help them open a pull request.
- No frameworks or build tools. Edit the HTML files directly.
- After editing, run `python3 scripts/update_site.py`.
- Do not invent facts, and never add passwords, keys or private information.
