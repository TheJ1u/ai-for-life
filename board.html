How the board works

This is a Kanban board, a simple way to see work moving from left to right. Teams use it to share priorities and avoid doing the same task twice. To move a card, edit board.html on GitHub and open a pull request. To suggest something new, open an issue.

New to this? See Start here and how contributions become resume proof.
