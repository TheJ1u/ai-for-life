Learning roadmap

A beginner path from using AI tools to building with them. Free or low-cost options first.

Stage 1: Use

  • Dictate prompts with Google AI Edge Eloquent.
  • Make a short video in Higgsfield or FLUX 3 and edit it in CapCut.

Stage 2: Connect

  • Learn what an API and an MCP connector are (see the glossary).
  • Set up a free GitHub account and make your first repo.

Stage 3: Build

  • Run a Hugging Face model in Google Colab.
  • Learn basic SQL for business analytics.
  • Try Claude Code to build a small tool.

Stage 4: Ship

  • Fine-tune or train a small model and publish it with a model card.
  • Write up the project for your portfolio and share it with the club.

Efficient ways to learn

  • Learn by building one small real project, not by watching hours of tutorials.
  • Keep a notes page of every prompt that worked.
  • Teach it back to the club. It is the fastest way to find gaps.
