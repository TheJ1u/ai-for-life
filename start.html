Three ways to get started

Brand new to AI? Take the AI 101 for beginners course first. Want to teach it to friends or a class? Use the facilitator guide and survey.

1. Try a tool

Pick one guide from the tools list and follow the steps. Start with whatever sounds most fun.

2. Come to a meeting

Every Thursday, 4:00 to 5:00 PM Mountain, at BYU. Add it to your calendar in one tap.

3. Copy a prompt

Grab a starter prompt from the library and see what happens.

Add to the site

This site belongs to everyone in the club. You can add a tool guide, a prompt, a project or a meeting note. The steps are on each page, and the whole process is explained in the GitHub guide.

  1. Make a free account at github.com.
  2. Open the club repo and click Fork.
  3. Edit a file, click Commit changes, then Open pull request.

Want to add a whole new tool guide? Copy the tool template and fill in each section. The contributing guide has the full checklist.

Not ready to edit? Suggest an idea and someone will pick it up.

Common questions

What is AI For Life?

A club for people who want to understand AI and use it in school, work and everyday life. We share what we are trying, swap tips, and help each other get started. No experience needed.

When and where do we meet?

Every Thursday, 4:00 to 5:00 PM Mountain, at BYU. Ask in the club chat for the room. The Meetings page has a calendar invite and notes from past weeks.

Do I need to know how to code?

No. Most of the tools here work in a browser or an app. If you want to learn the technical side, the Roadmap · By industry · News watch is a beginner path.

Does it cost anything?

Joining the club and using this site is free. Some tools have paid plans, but we point to free options first, and each guide notes the pricing to check on the official site.

Do I need a GitHub account to use this site?

No. Reading the site needs no account. You only need a free GitHub account if you want to add something to it.

What if I do not understand a word?

Check the Glossary. It explains terms like API, CLI, MCP, fork and pull request in plain English, and you can search it.

What if I break something when I contribute?

You cannot. Your edits happen in your own copy, and nothing goes on the site until it is reviewed and merged. Even after it is merged, every change can be undone.
