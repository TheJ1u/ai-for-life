Model hub

Hugging Face

The GitHub of AI: a place to find, test, share and run open models and datasets.

By Hugging Face

What it is

Hugging Face is a website and community where people publish AI models, datasets, and small demo apps called Spaces. It also makes popular open-source libraries such as Transformers. If a company releases open weights, they usually appear on Hugging Face first.

Why people use it

  • Free access to thousands of open models for text, images, audio and video.
  • You can try a model in the browser before writing any code.
  • It is the standard place to publish your own model or dataset, which looks great on a portfolio.

How to get started

  1. Create a free account at huggingface.co.
  2. Browse Models and filter by task (text generation, text-to-image, speech, and so on).
  3. Open a model page and read the model card: what it does, license, limits.
  4. Try it in the page widget or a Space. No code needed.
  5. When ready, run it in Google Colab (free GPU time) or call it through an API.

Try this

from transformers import pipeline

classifier = pipeline('sentiment-analysis')
print(classifier('Our new Medicare guide helped so many clients!'))

Your first code: 3 lines to run a sentiment model. Run it in Google Colab so you install nothing.

Why it matters for business and IS

Information Systems angle: open models let a startup avoid per-use API costs and keep data in-house, at the price of managing infrastructure.

Quick facts

  • Free to use; paid options exist for hosting and enterprise features.
  • Key words: Hub, model card, dataset, Space, Transformers, open weights, license.
  • Always check the license before using a model commercially.
